# Testimonials

A responsive Testimonials UI built with React.js and Tailwind CSS.

## 🚀 Features

- Responsive testimonial design
- Next and Previous testimonial buttons
- Dynamic testimonial data
- Clean and modern UI
- Built with reusable React components

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- JavaScript
- Vite
- React Icons
